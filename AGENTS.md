# Project Instructions & Rules

- **Strict Prohibition of AI-Generated Images**: Never use AI-generated images (`generate_image` or external generative models) for icons, graphics, or assets in this project.
- **Image & Icon Assets**: Use only exact user-provided assets, standard vector drawables (`VectorDrawable` / Material Symbols), or exact manual graphics as provided by the user.
- **Icon Usage**: Always use SVG/Vector icons instead of emojis.
- **Implementation Integrity**:
  - Do not remove, overwrite, or delete existing implementations unless explicitly instructed to do so.
  - Never use dummy code, fake implementations, or mock/sample/placeholder data.
  - Never alter app signing keys or keystore configurations (always keep standard debug keystore for compatibility).
  - Do not restore the "minimal app icon" feature.
